# Spendly Material 3 Expressive integration

## Why the assets are bundled

M3 Expressive Web 1.8.0 component CSS uses package-to-package CSS imports. Loading the component stylesheet directly from a CDN leaves those imports unresolved in the browser, so component styles are missing. The upstream HTML guide explicitly requires bundling the CSS with esbuild and hosting the generated file locally.

Official guidance: https://m3e.kyralabs.dev/get-started/html/

## Local setup

After switching to `feat/material-3-expressive-integration`:

```bash
npm install
npm run build
```

Use `npm install`, not `npm ci`, for this first setup because the M3E dependencies were added to `package.json` and the lockfile must be regenerated by npm.

The build produces:

- `assets/css/m3-expressive-app.bundle.css`
- `assets/css/m3e-fonts/*` (copied font assets referenced by the CSS)
- `assets/js/m3-expressive-app.bundle.js`

The shared header loads these local bundles only on pages that set `$enableM3Expressive = true`.

## Verify the build

```bash
test -s assets/css/m3-expressive-app.bundle.css
test -s assets/js/m3-expressive-app.bundle.js
node --check assets/js/m3-expressive-app.bundle.js

/opt/lampp/bin/php -l includes/header.php
/opt/lampp/bin/php -l dashboard.php
/opt/lampp/bin/php -l transactions.php
/opt/lampp/bin/php -l transaction-create.php
/opt/lampp/bin/php -l budgets.php
```

Then reload these pages with `Ctrl+Shift+R`:

- `http://localhost/spendly/dashboard.php`
- `http://localhost/spendly/transactions.php`
- `http://localhost/spendly/transaction-create.php`
- `http://localhost/spendly/budgets.php`

## Progressive enhancement

The existing transaction type radio inputs and transaction type filter select remain as fallbacks. They are hidden only after the M3E module has parsed, imported and initialized successfully.

The JavaScript listens to the M3E button group's documented `selection-change` event and the FAB menu's `action` event.

No database query, CRUD validation, authorization, authentication or CSRF implementation is changed by this integration.
